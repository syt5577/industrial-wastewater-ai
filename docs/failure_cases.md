## Failure Cases

当前 V1 已经完成核心链路，但在评估和真实业务测试过程中仍发现了一些典型失败案例。这些案例用于分析系统边界，并作为后续优化依据。

### 1. 危险废物判断问题召回不稳定

**问题示例：**

> 这个外委污水到底算不算危废，最后是哪个部门来判断的？

**现象：**

相关知识分别存在于部门职责、内部评估流程以及危废接收原则等多个 chunk 中。部分 Retrieval Evaluation 中，正确 chunk 无法稳定进入 Top-3。

**原因分析：**

该问题同时包含“危险废物属性判断”和“责任部门”两个意图，而知识分散在多个文档片段中，容易被其他包含“危废”“水质”“接收”等关键词的 chunk 干扰。

**后续方向：**

扩大 Evaluation Dataset 后，再进一步判断问题主要来自 chunk 设计、检索排序还是知识分布，并据此考虑 metadata 优化或 reranker。
