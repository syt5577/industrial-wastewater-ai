# 工业污水业务智能 Agent V0.2

## 1. 项目背景
    公司目前正在开展外接污水业务，该业务仍处于逐步建立和完善阶段。一方面，现有外接污水相关制度、SOP、客户资料及历史业务数据较为分散，部分流程和资料仍在持续补充完善；另一方面，外接污水业务本身具有较强的非标准化特征，涉及环保合规、生产处理能力、水质判断、商务报价、合同及结算等多个环节，不同客户之间的处理条件和价格差异较大。

    在实际业务开展过程中，业务人员既需要查询外接污水接收制度、SOP、客户资质、水质报告等非结构化资料，也需要结合客户历史水质、报价及实际成交价格进行判断。对于新的污水业务，仅依赖固定制度或单一计算公式往往无法直接形成合理的业务判断。
    
    因此，本项目拟构建一个面向外接污水业务的 AI Agent PoC，将企业制度知识、客户业务数据及确定性计算工具进行统一调用。
    
    系统主要希望实现以下能力：
    
    快速查询外接污水相关制度、SOP及业务要求，在业务人员不熟悉流程或职责边界时提供有依据的制度信息；
    
    查询客户历史水质、报价及成交数据，为新业务报价提供历史案例参考；
    
    根据新客户水质特征，检索相近水质区间内的历史客户及成交价格，为商务报价和谈判提供辅助参考；
    
    对涉及多类信息的业务问题，由 Agent 自动选择知识检索、客户数据查询及计算工具，减少人工跨文件、跨数据源查找信息的成本。
    
    本系统定位为业务辅助工具，不代替生产、环保、商务等专业人员进行最终决策，而是通过整合已有信息，为业务判断提供更及时、可追溯的参考依据。
## 2. 当前业务问题
    2.1 业务资料分散，查询成本较高

    目前外接污水业务相关信息分散在多类文件及业务资料中。
    
    制度及执行类资料包括：
    
        外接污水接收相关制度；
        
        外接污水业务 SOP；
        
        业务流程及职责要求。
    
    客户级资料包括：
    
        水质检测报告；
        
        外委污水业务评估单；
        
        月度污水处理明细；
        
        客户资质材料；
    
        历史报价及合同信息等。
    
    这些资料来源不同、格式不同，且单份文件信息密度有限。实际处理一个业务问题时，往往需要同时查询多份资料，人工检索效率较低。
    
    2.2 污水定价高度非标准化，固定公式难以直接支撑报价
    
    目前外接污水处理价格与水质之间并不存在简单的线性关系。
    
    从历史业务情况看，可能出现水质较差但成交价格较低，也可能出现水质较好但成交价格较高的情况。实际价格除水质外，还受到客户情况、污水量、市场替代方案、历史合作情况及商务谈判等因素影响。
    
    公司现有处理费计算思路可以依据客户水质指标与接收标准之间的倍数关系进行计算，但当部分污染指标较高时，按照固定公式计算得到的处理价格可能明显偏高，甚至接近或超过其他处置方式的市场价格，使报价失去实际商务可行性。
    
    另一方面，公司自身污水处理系统日常处理水量较大，部分外接污水进入系统后可能通过整体水量得到稀释，因此单批外接污水对应的真实边际处理成本并不容易准确拆分。
    
    因此，新客户报价实际上属于一个典型的非标准化决策问题，需要综合参考：
    
    客户水质；
    
        接收标准；
        
        历史类似水质客户；
    
    历史报价；
    
        实际成交价格；
        
        客户水量及其他商务条件。
    
    这也是本项目后续需要重点解决的业务问题之一。
    
    2.3 制度文件与实际业务执行之间可能存在偏差
    
    外接污水业务仍处于逐步完善阶段，现行制度及 SOP 与实际业务开展方式之间可能存在一定差异。
    
    实际工作中，一些流程可能已经根据业务需要发生变化，但制度文件尚未同步更新。如果 AI 系统仅依据已有文件回答问题，可能出现“制度内容正确，但与当前实际执行方式不完全一致”的情况。
    
    因此，本项目不能简单将 RAG 检索结果视为绝对业务规则，而需要关注知识时效性与版本管理。
    
    AI Agent 本身不负责决定制度如何修改，但可以通过检索历史业务记录、制度文件及实际操作资料，帮助业务人员识别制度与实际执行之间的差异，为后续 SOP 更新提供参考。
    
    2.4 新业务涉及多个部门，职责边界和协同路径不够清晰
    
    外接污水属于公司相对较新的业务类型，涉及发展与市场、生产、环保、安全、财务、法务等多个部门。
    
    在部分业务场景下，各部门对自身应承担的工作内容、审批责任及协同边界并不完全明确，业务推进过程中可能需要反复确认“该事项由哪个部门负责”“需要经过哪些流程”“依据哪项制度执行”。
    
    因此，业务人员经常需要重新查找制度、流程文件及历史案例。
    
    通过 Agent 对制度、SOP及历史业务流程进行统一检索，可以帮助业务人员快速定位相关职责要求，减少因信息不明确造成的沟通和推进成本。
